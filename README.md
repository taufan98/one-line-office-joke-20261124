A program that writes one original funny line about office life to
`/output/entry.txt` — an entry for
[One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)
on make.fun. A house judge compares the lines pairwise: a setup everyone in
an office recognises, a punchline that turns it back on itself, and economy
of words.

## The line

> My manager said the meeting could have been an email, then sent a 40-slide deck recapping the meeting that could have been an email.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (132 characters, within the 1–200 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-liner to `entry.txt`.
